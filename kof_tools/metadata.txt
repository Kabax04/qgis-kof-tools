description=Import KOF survey files (the Norwegian coordinate file format) as points, lines and polygons, and export point, line and polygon layers to KOF.
about=KOF is the coordinate file format used by Norwegian surveying instruments and software (Norkart KOF specification 2.00). The plugin reads points (05 records), lines and polygons (09 blocks), GNSS vectors (42/43 records) and the file header, detects the coordinate reference system (EUREF89 UTM and NTM, NGO1948, ED50, WGS84 UTM and more) and checks the axis order. Repeated measurements of the same point can be merged into mean points with standard deviations. Point, line and polygon layers can be exported to KOF files, with the coordinate system code in the header. Use it from Vector > KOF Tools, the Processing toolbox, or by dragging a .kof file onto the map. The user interface is available in English and Norwegian.

changelog=1.4.1
    - Points with irregular columns are no longer misread: an ambiguous code and coordinates are reported instead of guessed, and a warning says how many points were read word by word
    - Files without the blank first column, or indented further, are read in the right columns, so point names and codes are no longer cut short
    - Arcs (09 93) from the import are exported as 09 93 with their measured points, instead of hundreds of numbered vertices
    1.4.0
    - Import GNSS vectors (42/43/44/46 records, e.g. from Topcon MAGNET Tools) as a line layer
    - An unreadable point with tabs is reported as a warning instead of stopping the import
    1.3.1
    - Dropping a .kof file shows the real error when the import fails, and only opens the dialog when the file has no coordinate reference system
    - Exporting a layer without a coordinate reference system warns that the coordinates are written unchanged
    1.3.0
    - Export line and polygon layers to KOF as 09 blocks (09 91 … 09 99, closed with 09 96)
    1.2.0
    - Export point layers to KOF files (Vector > KOF Tools > Export to KOF…)
    - Renamed from KOF Import to KOF Tools (plugin folder kof_tools); uninstall KOF Import after installing
    1.1.0
    - Works in QGIS 4 (Qt6) as well as QGIS 3.22 and later
    1.0.1
    - The axis order check only swaps north and east when the swapped coordinates fit Norway in UTM or NTM, so local coordinates are left alone
    1.0.0
    - English user interface with Norwegian translation (bokmål and nynorsk)
    - Field names in English
    - Coordinate system codes from the 01 block cover all SOSI codes, including NTM zones 5-30
    - CRS recognised from ArcGIS export text and SRID/EPSG comments
    - Axis order is checked and corrected when the file states it wrongly
    - Points with missing north or east are reported instead of misread
    - First stable release
